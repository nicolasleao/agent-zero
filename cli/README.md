# Agent Zero CLI

Terminal chat interface for Agent Zero.

## Install

```bash
pip install -e cli/
```

## Run

```bash
agentzero
```

## Configuration

Create a `.cli-config.json` in the current directory or in `~/.agentzero/`:

```json
{
  "instance_url": "http://localhost:5080",
  "theme": "dark"
}
```
